# Effect of Calendar-Based Exogenous Variables on TFT Performance Across Forecast Horizons

This figure compares the forecasting performance of the Temporal Fusion Transformer (TFT) with and without calendar-based exogenous variables on the ECL and PJM datasets. The evaluation metric is Normalized Mean Absolute Error (Normalized MAE), where lower values indicate better forecasting accuracy.

<img width="2997" height="1126" alt="fig_table_5_4_tft_ecl_pjm" src="https://github.com/user-attachments/assets/d8baa489-4333-480e-856e-6fc01e9ba66c" />

This figure shows the normalized MAE of TFT across different forecast horizons for the ECL and PJM datasets. Adding calendar-based exogenous variables consistently reduces forecasting error in both datasets, with stronger improvements visible for longer horizons, especially on ECL.
